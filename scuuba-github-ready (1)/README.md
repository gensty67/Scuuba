# SCUUBA — Premium Coming Soon / Development Website

A complete, multi-file web project built for Scuuba's upcoming September 1 launch.

## Project Structure
- `index.html`, `about.html`, `privacy.html`, `terms.html`, `404.html`
- `css/`: Modular CSS files (main, responsive, animations, components, maintenance)
- `js/`: Modular JavaScript files (config, countdown, progress, contact, navigation, theme, storage, utils, animations, main)
- `assets/`: Scalable SVG graphics and logos
